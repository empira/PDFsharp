## What’s new in version 7.0.0 Preview 2

### Breaking changes

**AGPL or Commercial License**  
Beginning with version 7.0.0 Preview 2, your code must select the type of license to be used.

#### Load the AGPL license

To load the free AGPL license, insert the following code:

```CS
PdfSharpLicense.SetAgplLicense();
```

#### Load a commercial license

If you need a commercial license, contact us at <https://pdfsharp.com/Pricing>.  
You will get your license key, which you can load as follows:

```CS
PdfSharpLicense.LoadLicense(YourLicenseCode);
```
